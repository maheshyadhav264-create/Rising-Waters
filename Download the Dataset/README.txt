FLOOD PREDICTION USING MACHINE LEARNING
=========================================

FOLDER STRUCTURE
----------------
code/
  generate_dataset.py   - Generates the synthetic flood dataset (see note below)
  flood_prediction.py   - Full ML pipeline: EDA, training, evaluation, plots

dataset/
  flood_dataset.csv     - 1200-row dataset (TEMP, HUMIDITY, CLOUD_COVER,
                           monthly rainfall JAN-DEC, JUN_SEP, ANNUAL, FLOOD)

plots/
  All figures generated by the pipeline (EDA + model evaluation charts)

report/
  Flood_Prediction_Report.docx   - Full written report (Word)
  model_comparison_metrics.csv   - Accuracy/Precision/Recall/F1/ROC-AUC per model
  classification_report.txt      - Detailed sklearn classification report

HOW TO RUN
----------
1. python3 generate_dataset.py     (creates dataset/flood_dataset.csv)
2. python3 flood_prediction.py     (trains models, saves plots + metrics)

Requires: pandas, numpy, matplotlib, seaborn, scikit-learn

NOTE ON DATA SOURCE
--------------------
The original request pointed to the Kaggle dataset "arbethi/rainfall-dataset".
Kaggle requires an authenticated session to download files directly, which
isn't accessible in this environment, so a synthetic dataset was generated
that mirrors the same feature structure (Temp, Humidity, Cloud Cover, monthly
rainfall, ANNUAL) with realistic statistical relationships between rainfall,
humidity, cloud cover, and flood occurrence. If you have Kaggle API access,
you can substitute the real file at dataset/flood_dataset.csv (matching
column names) and re-run flood_prediction.py directly.
